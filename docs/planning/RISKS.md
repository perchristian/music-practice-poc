# Risks

## Domain Risks

| Risk | Likelihood | Impact | Mitigation | Current status |
| --- | --- | --- | --- | --- |
| Poor stem separation quality from screen-recorded, compressed, noisy, or mixed sources | Medium | High | Keep mock mode demoable; test real recordings early; compare multiple separators only after first real spike | Partially mitigated. Demucs `htdemucs_6s` was accepted as good enough for the `MakeYouFeelMyLovePart2.mov` play-along workflow, but more songs are still needed |
| Piano leaks into `other`, `guitar`, or `vocals` stems | Medium | High | Inspect separated stems manually; choose stem strategy based on learning value, not purity | Still open. Demucs improves the accompaniment use case, but solo piano crackle/artifacts and leakage remain possible |
| Non-piano stems are too poor after separation to be useful for play-along practice | Low | High | Evaluate drums, bass, guitar, and piano stems together; prioritize a useful accompaniment over perfect isolation | Partially mitigated for one real clip. Demucs piano removal was good enough for POC play-along on `MakeYouFeelMyLovePart2.mov` |
| Basic Pitch or another transcription tool produces inaccurate MIDI for dense polyphonic piano | High | Medium | Treat transcription as approximate cues; test alternatives only if cues are unusable | Open |
| Beat/bar grid is wrong or drifts because Bar 1, tempo spans, or mid-song meter changes are misidentified, making chord placement, loops, count-in, and practice notes misleading | Medium | High | Analyze timing before harmony; keep the grid audible and analyzer provenance immutable; use one bar-line editor for downbeat time and effective meter; derive tempo sparsely between bar events; use a threshold-aware timing benchmark that rejects ordinary beat jitter while detecting persistent phase/tempo changes | Partially mitigated. Version-2 timing events represent downbeat and meter changes through one bar line, and seven generated fixtures pass the locked sparse-timing gate with at most 60 ms bar error. Human review passed changing-tempo and late-start recordings for corrected click, loops, count-in, reload, and chord highlighting. Loop-entry, snapshot remapping, and bar/beat-authoritative boundaries are automated and human-confirmed. Broader song and device coverage remains open |
| Chord detection is wrong or misleading because melody, ornaments, missing bass, separation leakage, or independent repeated-section estimates dominate stable accompaniment harmony | High | High | Treat chord reliability as a pre-feature validation gate; benchmark reference-timed and end-to-end analysis separately on a new locked split plus reviewed iOS screen recordings; make per-stem evidence inspectable; test accompaniment-first melody suppression, reliability-gated bass fallback, persistence-weighted comp evidence, and known-group repetition pooling independently; preserve user-owned charts and compare an external analyzer after two failed local attempts on one error class | Confirmed core blocker. Isolated-beat smoothing raises development MajMin from 58.6% to 60.8% with oracle timing and 53.7% to 55.7% end-to-end, but the consumed holdout remains only 49.0% and 39.9%. Human review of `ShapeOfMyHeart manually adjusted` found inaccurate chord names after corrected-timing reanalysis. `docs/research/chord-reliability-validation-plan.md` now defines a bounded seven-milestone gate before unrelated feature work resumes |
| Returning to analyzer suggestions destroys a user's chord work | Low | High | Require explicit confirmation; snapshot the exact chart against the active analysis identity; permit one-step undo only before newer edits; never merge or train on user work | Mitigated for the POC. Both ordinary reset and corrected-timing replacement preserve an analysis-scoped backup, stale identities are rejected, and automated backend/browser coverage verifies exact restore |
| Benchmark results overfit one corpus or fail to represent screen-recording audio | Medium | High | Stratify RWC-P by chord and instrumentation complexity; use the fixed holdout only as a regression checkpoint; use synthetic/solo-instrument corpora only for diagnostics; finish with reviewed real iOS screen recordings covering bass/no-bass, melody/ornaments, and repeated variation | CR0 now locks a fresh 8-development/4-holdout RWC-P split that excludes all consumed Phase 2J tracks, inventories five checksum-locked target development candidates, and reserves two full-length untouched target holdout slots. The holdout identities and independently reviewed target references remain open product-owner inputs. RWC-P remains cleaner than screen-recording audio and is CC BY-NC, so media stays outside shipped/demo assets |
| CPU-only processing is too slow for a convincing demo | Medium | High | Keep mock mode default; measure first real subsystem before committing to full real pipeline | Still open for user-length recordings. Demucs completed the 23-second bakeoff clip and a short end-to-end smoke locally, but longer screen recordings need measurement |
| Full-song harmonic analysis exhausts memory or becomes too slow | Medium | High | Analyze a reduced-rate mono representation, retain a bounded upload guard, and regression-test cues beyond two minutes | Partially mitigated. The 120-second truncation is removed and a 125-second fixture completes with cues after 120 seconds; the upload guard is now 650 MB to accommodate five-minute screen recordings, while runtime and peak memory still need measurement on several real user-length recordings with all supporting stems |
| iOS Photos permissions, large video uploads, and App Transport Security create friction | Medium | Medium | Start with web/local uploader; revisit native only if upload friction blocks validation | Open |
| Copyright and user expectations around commercial recordings | High | Medium | Document demo media limitations; avoid bundling commercial media | Open |

## Dependency and Platform Risks

| Risk | Likelihood | Impact | Mitigation | Current status |
| --- | --- | --- | --- | --- |
| Heavy ML dependencies slow or fail installation | High | High | Keep default mock mode dependency-light; add real dependencies only through explicit setup | Partially mitigated locally with `.venv-real`, `requirements-real.txt`, and `.cache/torch`; still a setup risk on new machines |
| Lightweight FFmpeg separator gives false confidence before testing ML-quality separation | Low | High | Label Phase 2G outputs as heuristic, require human listening, and do not infer real source-separation viability from generated media alone | Mitigated for current direction. Human listening rejected FFmpeg quality and accepted Demucs for POC play-along |
| FFmpeg unavailable in development environment | Medium | Medium | Do not require FFmpeg for mock mode; document real-mode setup; return a clear missing-FFmpeg error in real mode | Mitigated locally on 2026-07-06 by Homebrew install; verified `/opt/homebrew/bin/ffmpeg` version 8.1.2. Automated missing-FFmpeg coverage now verifies the failure path |
| Browser audio behavior differs across desktop and iOS Safari | Medium | Medium | Use native HTML audio APIs first; test on target devices before user sessions | Open |
| Multiple HTML audio elements drift during synchronized stem playback | Medium | Medium | Keep sync simple in mock mode; measure drift manually; move to Web Audio if drift distracts from the demo | Open |
| Large uploads consume local disk or memory | High | High | Keep a 650 MB hard cap; run the local backend on a machine with sufficient free memory and disk; replace multipart buffering with streaming upload storage before broader real user testing | Open for five-minute recordings. The cap now accommodates the observed screen-recording bitrate, but the multipart parser and WAV reader still buffer source data in memory, and peak memory/disk usage has not been measured with a near-limit upload |
| GUI verification depends on Playwright browser installation | Medium | Low | Keep Playwright dev-only; document `npx playwright install chromium`; backend tests still run without browser binaries | Mitigated |
